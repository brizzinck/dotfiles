# Secret locations of the owner's home that must be owner-only (group and other bits 0). Read by home-acl.sh: `apply` removes
# the group/other bits below each path once (directories become 0700, files 0600, or 0700 when the owner could execute them),
# the doctor check `home-acl` fails when one is wider again. One path per line: PATH [full|top]   (` #` starts a comment)
#   PATH   relative to the owner's home, absolute, or @REPO@/... (the dotfiles checkout); a missing path is skipped, a symlink
#          is skipped (its target is not followed, list the target separately)
#   full   everything below must stay owner-only: nothing but our scripts writes there
#   top    (the default) only the path itself is checked: an application keeps creating files there with its own umask (022),
#          so the directory with 0700 is the lock (nobody else can traverse it); apply still tightens everything below once
# Sources: CLAUDE.md (Users, MCP gateway, Passwords and 2FA, Telegram, Bitwarden), install.sh and what the home really holds.
