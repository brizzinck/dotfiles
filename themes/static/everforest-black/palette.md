# Everforest Black has moved

The palette is now "Everforest palette v2" with two variants (black, night): `themes/palette/palette.md` is the
human-readable source of truth, `themes/palette/everforest.json` the token source, and `themes/generated/{black,night}/`
the rendered fragments (ghostty, alacritty, tmux, fzf, delta, waybar.css, rofi.rasi, ansi.txt, tokens.json,
tokens.css, claude-theme.json). The old fragments in this directory were replaced by those generated files.
