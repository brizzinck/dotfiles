### Update tool (sysup)
`sysup` is `.local/bin/sysup` (no zsh function). **Check + download run in the background, the install only when the owner starts it** (waybar updates click, `SUPER+SHIFT+U`, `sysup`, hub Update group): the user timer `sysup-check` (2 h) writes `~/.local/state/sysup/pending.json` (checkupdates, AUR, flatpak, npm -g) and pokes the badge; the root timer `dotfiles-predownload` (`infrastructure/pacman/dotfiles-predownload`, installed by `apply-system.sh --only services`, AC power only) runs the `checkupdates -d` method (private database copy, nothing installed, no partial-upgrade state) plus `flatpak update --no-deploy`. One install run (`sysup --help`, `sysup steps`): free space, Arch news + one confirmation, `paccache -rk2`, keyring first, `yay -Syu --noconfirm` (AUR without PKGBUILD review), flatpak, rustup + cargo crates, `npm -g update` (Codex, Gemini, ACP), pipx/uv, `go install @latest` of every module-built binary in `~/go/bin`, mise tools (global config only; the run starts with `cd $HOME`), `claude update`, nvim (`scripts/update.lua` of the nvim fork: `Lazy! update`, Mason, treesitter; `lazy-lock.json` is committed in the submodule and the gitlink in this repo, never pushed), oh-my-zsh + plugins, tpm, then pacnew, reboot/restart hints, failed units. The whole run holds a sleep/idle/lid inhibitor and is logged to `~/.local/state/sysup/last.log`. Firmware stays hub rows; rollback is the hub row "Downgrade a package" (AUR `downgrade`, the pacman cache keeps two versions). Tests: `infrastructure/tests/sysup/run.sh`.
