# Dictation (Voxtype)

Topic file of the agent docs. `CLAUDE.md` holds the index, the rules that apply everywhere and the file of every section; section names quoted in the text ("Users", "Dev tools", ...) are listed there.

### Dictation (D1b)
Offline voice typing: Voxtype (AUR `voxtype-bin`) + local Whisper, typed into the focused window; nothing leaves the machine. `.config/hypr/scripts/dictation.sh` is the only entry point (`toggle|start|stop|cycle|lang|model|backend|status|--follow|run|menu`), `voxtype.service` runs `dictation.sh run`. **Language**: default `ru` (tracked `.config/voxtype/config.toml` and the script when no state file exists), remembered in `~/.local/state/dictation/lang`; accepted values `ru`, `uk`, `en`, `auto` and comma lists such as `en,ru,uk` (auto-detect among them; `auto` cannot be mixed into a list). `SUPER+ALT+SHIFT+D` (and the waybar middle click) cycles ru -> uk -> en -> ru (anything else starts at ru), restarts the daemon with `try-restart --no-block` and shows ONE replacing notification (`Dictation: RU`, stack tag `dictation`); while recording or transcribing it refuses ("Dictation is busy"). `run` renders a runtime copy of the tracked config with the language and model, so the tracked file never changes. **Indicator** (`custom/dictation`, always visible while voxtype is installed): `󰍬 RU` grey (`dim`) idle, `󰍬 RU rec` red_soft (`critical`) recording, `󰔟 RU` yellow_soft (`warning`) transcribing; tooltip = state, language, model, backend, then `L: dictate · M: next language · R: menu`; `--follow` forks nothing while idle (builtin reads of the state, language and model files every 0.5 s, `installed` re-checked every 10 s, `systemctl is-active` only when the state file is missing or unknown and then at most every 10 s, the backend cache re-read only when its mtime is newer than a per-instance stamp `$XDG_RUNTIME_DIR/dictation-follow.PID`, `jq` only when the output changes; it was about 350 forks/min per bar); right click = menu (toggle, next language, language list incl. `en,ru,uk`, model small / large-v3-turbo, "Backend: detect again"); hub rows `dictation*` and leader `a v/c/l/b`. **Backend** (no root, no PATH hack, no systemd drop-in): the package ships `/usr/lib/voxtype/voxtype-{vulkan,avx512,avx2,baseline}`; `run` execs the chosen variant directly. Vulkan when a real GPU works: a silent 1 s clip is transcribed once with the smallest installed model and the log must show `using Vulkan` (llvmpipe/lavapipe/swiftshader do not count); the result (backend, GPU name, reason) is cached in `~/.local/state/dictation/backend` and keyed on the Vulkan build, the ICD json files and the kernel, so an upgrade re-probes; no model yet = no probe and no cache; two automatic restarts of the unit (`NRestarts >= 2`) demote a crash-looping Vulkan daemon to CPU until `backend --probe`. CPU fallback by `/proc/cpuinfo` flags: avx512 (f, bw, vl, dq) > avx2 (avx2, fma) > baseline, skipping builds that are missing, last resort the `voxtype` on PATH. Env hooks for tests: `VOXTYPE_BIN` (replaces client and daemon binary), `VOXTYPE_LIBDIR`, `DICTATION_CPUINFO`. The client (`voxtype record start|stop`) only signals the daemon, so `/usr/bin/voxtype` (avx512) is fine for it. doctor `dictation-backend` (the daemon's `/proc/PID/exe` is the variant `backend --path` names; FAIL on a leftover runtime drop-in or `~/.local/share/voxtype/bin/voxtype`), `o1-tests` (independent of whether the package is installed: `VOXTYPE_BIN` points at a fake or at a missing file). **Model benchmark** (2026-10-17, AMD Radeon 860M Vulkan, `voxtype transcribe` per clip so every number includes process start and shader setup; clips: piper TTS ru/uk/en sentences of 2 to 4 s with known text, plus three 10 to 22 s public-domain human recordings from Wikimedia Commons; no microphone): small 0.38-0.56 s per clip (0.71 s for 22 s), large-v3-turbo 1.3-1.6 s (3x slower, 1.6 GB vs 466 MB); on CPU avx512 small takes 6-8 s and turbo 33-41 s, so Vulkan is 12-25x faster. Word error rate (digits counted as errors for both models): ru small 0.07 / turbo 0.17, uk small 0.35 / turbo 0.23, en 0.02 / 0.02; on the human clips small was as good or better in ru and uk (turbo dropped the URL in ru and garbled the uk sentence). Turbo is not clearly more accurate and sits at the speed limit (about 1.4 s for a 3 s clip), so the default stays `small`; `large-v3-turbo` (`ggml-large-v3-turbo.bin`, downloaded, 1.6 GB) is selectable from the menu or `dictation.sh model large-v3-turbo` (remembered in `~/.local/state/dictation/model`; `dictation.sh model small` goes back). The Telegram voice transcription keeps its own copy of `small` (`/srv/models`).
