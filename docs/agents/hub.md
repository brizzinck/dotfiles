# Hub, window tools and desktop helpers

Topic file of the agent docs. `CLAUDE.md` holds the index, the rules that apply everywhere and the file of every section; section names quoted in the text ("Users", "Dev tools", ...) are listed there.

### Hubs and window tools
- `hub` (`.config/hub/`, `SUPER+M`, tmux `prefix m`, zsh `hub`): fzf utility hub in a `float.tui` ghostty. Rows come from `actions.tsv` (+ `actions.d/*.tsv`; format in the header of `.config/hub/hub`) merged with every described bind from `hyprctl binds -j`; keybind rows are executable (below); toggles show live ON/OFF; rows whose command is not installed are hidden. `hub open` records the previously focused window (`$XDG_RUNTIME_DIR/hub/prev-window`) so window actions target it. Later stages append rows to `actions.tsv`. `SUPER+P` is the project picker `pj` (hub row `projects`, leader `j p`; see "Projects").
- `scripts/window-menu.sh` (`SUPER+SHIFT+W`, fzf-menu): per-window actions with `address:` dispatchers; `--dry-run --do ID` prints the dispatcher. Extra entries come from executable files in `scripts/window-hooks/` (`# menu: Label` line; run as `hook ADDRESS`).
- `scripts/window-switcher.sh` (`SUPER+SHIFT+space`): fuzzy switcher over all windows. `scripts/safe-close.sh` (`SUPER+W`): double press within 1 s for the classes in `.config/hypr/protected-classes`. A terminal window owns its tmux session: `SUPER+Return` starts `term-*`, and the `session-created` hook in `tmux.conf` sets `destroy-unattached on` for it (no `-t`: tmux does not expand formats in `-t`, the old hook never matched), so closing the window kills the session; `SUPER+W` therefore says "Closes ..." (sessions that predate the fix still say "Detaches ..."). Leftover unattached `term-*` sessions: hub row "Clean up detached terminal sessions" (`SUPER+; f d`) or `prefix X` then `D` (`kill-session.sh --detached`: multi-select, shows the foreground commands from `term-procs.py --detached`, confirms). `infrastructure/tests/tmux-destroy/run.sh` (doctor `tmux-destroy`) tests the hook and the cleanup in a private tmux server.
- Desktop vim (V1a): `SUPER+;` is the leader (`wlr-which-key`, AUR): `.config/hub/leader` renders its YAML on every open from the hub rows (`leader` column = `group-key item-key;label`, groups in `.config/hub/leader-groups.tsv`, `leader check|gen|md`), look from the palette (`wlr-which-key.yaml.tmpl`), `auto_kbd_layout` for ua/ru; every item runs `hub --leader ID`, so the leader and the hub cannot drift. Keyboard pointer (`wl-kbptr` + `wlrctl`, AUR): `SUPER+'` hint click, `SUPER+CTRL+'` hint drag, `SUPER+ALT+M` the `mouse` submap, all through `scripts/pointer.sh` (shows a notification when a tool is missing; wl-kbptr reads its labels from the active layout, so the script switches to us and back); overlay colours from `wl-kbptr.conf.tmpl` through `~/.config/wl-kbptr/config`. Window grammar: `SUPER+ALT+H/L` group tab, `SUPER+ALT+J/K` workspace on this monitor, `SUPER+ALT+SHIFT+HJKL` into a group, `SUPER+CTRL+Y` out, `SUPER+ALT+X` dunst context menu (drawn with dunst's `dmenu = fzf-menu -p dunst`). The full grammar is in `docs/keymap.md`. OBS: leader group `o` and hub group OBS (`actions.d/v1c.tsv`) run `.local/bin/obs-ctl` (obs-cmd over obs-websocket: record, pause, scene and mute pickers, replay save, status, menu; streaming only in the menu and only with a stream key). The one-time setup is in OBS (Tools > WebSocket Server Settings > Enable); `obs-ctl` reads port and password from OBS's own `obs-websocket/config.json` (or `OBS_WEBSOCKET_URL` / `~/.config/obs-cmd/url`) and hands the URL to obs-cmd through its environment, never argv or the repo. Offline test: `infrastructure/tests/obs-ctl/run.sh` (doctor `obs-ctl`).
- Passwords and 2FA: `docs/agents/vault.md`; the vault reorganisation (BW-ORG) and the vault-share broker: `docs/agents/vault-org.md`.

### Hub groups, desktop helpers (O1)
The hub has ordered groups (`.config/hub/groups.tsv`): Setup, Update, Learn, Fix, Toggles, Capture, ...; `hub groups`, `hub open <group>`, `hub --json` (rows for agents) and "install" rows for a missing tool listed in `install-hints.tsv`. Binds added by O1 (all in `docs/keymap.md`): `SUPER+ALT+D` / hold `F9` dictation, `SUPER+ALT+SHIFT+D` next language (Voxtype, `dictation.sh`, waybar `custom/dictation`; see "Dictation (D1b)" below), `SUPER+CTRL+E` edit anywhere (`edit-anywhere.sh`, see "Edit anywhere (E1)"), `SUPER+ALT+T` / `SUPER+CTRL+ALT+T` reminders (`reminder.sh`, transient systemd user timers), `SUPER+CTRL+Delete` laptop panel on/off (`lid.sh panel`: refuses without an external monitor, the `monitor.removed` hook restores it), `SUPER+CTRL+ALT+Delete` mirroring, `SUPER+CTRL+Z` zoom, `ALT`/`SHIFT` volume and brightness steps, `SHIFT+Mute` next output, `SUPER+CTRL+period` transcode. Captures end in toasts (`capture-lib.sh`): the screenshot toast opens satty on a click, recordings are trimmed and loudness-normalised and get a thumbnail toast; OCR and QR select on the frozen screen. `crash-watch.sh` (user service) toasts when one of your programs dumps core. `SUPER+W` on a terminal says what dies (`term-procs.py`). The idle dim goes through `dim.sh` (saves the raw brightness only while no dim is active, restores from the state file; key press, pointer move and the `hypridle-watch` timer are the safety nets); `misc:key_press_enables_dpms` / `mouse_move_enables_dpms` wake a panel hypridle switched off. The lock goes through `lock-screen` (layout reset to us first). Tests: `infrastructure/tests/{o1,safe-close,sysup}/run.sh`.

### Edit anywhere (E1)
`SUPER+CTRL+E` (hub row `edit-anywhere`, leader `e`) opens a small floating ghostty (class `float.edit`, window rule `float-edit` = float + 900x360 fallback) with nvim at the mouse pointer, for text fields that have no vim. `.config/hypr/scripts/edit-anywhere.sh open` records the focused window (like `hub open`: `HUB_TARGET` or `tg_record`), takes the primary selection as the starting text (`wl-paste --primary`; skipped for password-manager hints, non-text and over 100 KB, and when starting from a terminal, because a terminal does not replace a selection on paste) but only when it is fresh: the primary selection lives until something else is selected, so a text selected hours ago in a terminal used to come back in every editor. The autostart watcher `edit-anywhere.sh _watch` (execs `wl-paste --primary --type text --watch edit-anywhere.sh _seen`) writes `seen` (epoch, active window address, sha256 of the text, never the text; `CLIPBOARD_STATE` nil / sensitive removes it; the event wl-paste sends in the first second for the selection already there is ignored, it was not made in the window active at that moment), and `open` preloads only when the window, the fingerprint and the age (`EDIT_ANYWHERE_MAX_AGE`, 120 s) match; every real `open` removes `seen`, so one selection is preloaded once at most. Without the watcher nothing is preloaded (doctor `edit-watch`), puts it into `$XDG_RUNTIME_DIR/edit-anywhere/text.txt` (tmpfs, 0700, removed after every run), computes the geometry (window centred on the pointer, clamped to the work area of the monitor under the pointer, bar reserved zone and a 8 px margin respected, shrunk on a small monitor) and launches the terminal through `hyprctl dispatch hl.dsp.exec_cmd(cmd, { float, move, size })` (the `move` of an exec rule is monitor-relative). The terminal runs `edit-anywhere.sh _session`: `nvim -n -i NONE -c 'luafile edit-anywhere.lua'`, so the owner's nvim config is untouched (K3 layout auto-switch is part of it and works; the helper only sets buffer-local things in a VimEnter autocmd and does nothing without `EDIT_ANYWHERE_DIR`). The buffer starts in INSERT at the end of the text, `filetype=markdown` (render-markdown shows it in NORMAL, the raw text in INSERT; Telegram turns `**bold**` into bold when it sends), wrap + linebreak, no swap/undo/numbers, `nofixendofline noendofline` so the text is written exactly (a one-line text has no trailing newline, a trailing newline typed by the owner is kept). **Finish** = `Ctrl+S` (insert, normal, visual; also on the ua `і` and ru `ы` keys), `ZZ` or `:wq` (any write of the buffer is the marker `saved`; `:w` followed by closing the window therefore also counts); **cancel** = `:q!`, `ZQ` or closing the window (SIGHUP, the session directory is wiped); `Esc` stays `Esc`. Finish (`_finish`, detached so the window can close): empty text = nothing pasted; the text goes to the clipboard with `wl-copy -t text/plain`, wait for the editor window to be gone, focus the recorded window (`hyprd focuswindow`), `type-guard` (`tg_ok`: only paste when that window really has focus), `paste_send` from `paste-lib.sh` (the physical V key: `CTRL`, terminals `CTRL SHIFT`, so it works on any layout and needs no `wtype`; the wtype fallback stays), The text stays on the clipboard afterwards (the owner wants to paste it again elsewhere; the old clipboard is not put back, cliphist keeps it). Closed target = text stays on the clipboard with a notification. The keyboard layout active when the key was pressed is restored when the editor closes (K3 switches to us in NORMAL). Verified live against throwaway windows (a GTK entry whose selection is replaced, a ghostty terminal; keys sent only to those addresses with `send_shortcut`): selection preload, Ctrl+S in insert and after Esc, ZZ, cancel by closing. Tests: `infrastructure/tests/edit/run.sh` (geometry, preload rules, finish/cancel/empty/gone/focus lost, paste shortcut per class, fresh-selection rules, the text kept on the clipboard, layout restore, the exec-rule command, and the Lua helper headless with `nvim -u NONE`), doctor `edit-tests`. Test hooks: `EDIT_ANYWHERE_DIR`, `_TERMINAL`, `_NVIM`, `_NVIM_ARGS` (one argument per line), `_MAX_AGE`, `_NO_NOTIFY`, `_SYNC`, `_KEEP`.
