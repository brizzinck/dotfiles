# Projects (pj)

Topic file of the agent docs. `CLAUDE.md` holds the index, the rules that apply everywhere and the file of every section; section names quoted in the text ("Users", "Dev tools", ...) are listed there.

### Projects (DEV-c: pj)
`pj` (`.local/bin/pj`, one Python stdlib file, pattern of `vault-browse.py`) replaces `sessionizer.sh`: **one project = one tmux session**, picked from one list. Keys (all layout-independent): `SUPER+P` (`pj open`, Hyprland), tmux `prefix F` (popup, `pj --here --client '#{client_name}'`), zsh `Ctrl+X p` (INSERT/emacs) and NORMAL `gp` (`pj-widget` in `vi-mode.zsh`, ua/ru twins like `gs`), hub group Dev rows `projects` / `projects-task` / `projects-clone` (`actions.d/dev-c.tsv`, leader `j p` / `j w` / `j g`), `pj DIR` (`pj .`) / `pj NAME` without a picker, `pj create DIR` (session without showing it). **Why not sesh**: AUR-only (`sesh-bin`, 3 votes, one sha256 copied for three arches), an 11.5 MB Go binary that needs 47 ms before it has listed anything we use (`sesh list --no-cache` 47 ms, `tmux list-sessions` 1.7 ms, `zoxide query -l` 1.4 ms), its own worktree/clone/picker models compete with workmux and our modal fzf-menu, and it has no per-repo layout file with trust, `term-*` handling or Hyprland window reuse; `pj rows` costs about 45 ms in total including Python start (gate G1 <= 60 ms; `fd` is not used: it finds 85 "repos" with submodules and cannot prune at a repo). **Rows** (`ID<TAB>display`, ids `s:NAME` / `r:/abs` / `w:/abs` / `z:/abs`): running sessions by activity (a detached `term-*` that still runs something first, then project sessions = `@pj_path` set, other named ones, other `term-*`; `●` attached `○` detached, windows, the busy commands of a `term-*`), every git repo under the roots (an `os.scandir` walk that stops at the first directory with a `.git` directory, skips dot dirs and `node_modules vendor target build dist venv .venv __pycache__`, depth 4; a `.git` file = linked worktree or submodule, never a repo of its own; branch from `.git/HEAD`, no fork; the walk has a budget of 20000 directory entries / 40 ms, and when it runs out the repos of the last complete walk that still exist fill the list, from `~/.cache/pj/repos.txt` (`KEY<TAB>repo` lines, 0600, rewritten after a complete walk when the list changed)) with its newest 3 linked worktrees (HEAD mtime) right behind it as `repo ⎇ branch` (read from `.git/worktrees/*/gitdir`, prunable ones skipped; `workmux list` costs 163 ms per repo) and the rest behind one `repo ⎇ +N worktrees` row (Enter shows them: the list reopens with that repo expanded); a worktree in the temp dir (`$TMPDIR`, else `/tmp`) of a repo that does not live there is an agent's scratch checkout and is not listed (its branch still counts as used in the branch picker), then the top 30 zoxide dirs (`z`, existing, minus `$HOME`, `/` and everything already listed). A repo or worktree whose session runs is folded into the session row. **Config** per user, not in the repo: `${XDG_CONFIG_HOME:-~/.config}/pj/config.toml` with `roots = ["~/job", "~/dotfiles"]`, `depth = 4`, `zoxide = 30`, `clone_dir = "~/job"`, `ai_autostart = false`; a missing file = these defaults, a broken one = defaults plus the error (doctor `pj` fails). **Session name**: basename with `.` `:` space `#` -> `_` (`#` starts a tmux `#(shell)` job: tmux format-expands `-s`, `-c` and `-n`, so every directory passed to tmux goes through `lit()`, `#` -> `##`, and no name can contain one); digits only, `term-*` or a name that does not start with `[A-Za-z0-9_]` get a `p-` prefix (so the throwaway rules of `prefix N`, `kill-session.sh -u` and the `session-created` hook never match a project session, which therefore never gets `destroy-unattached`; and `=$1` is not read by tmux as the session id `$1`: a session whose name starts with another character, e.g. one not made by pj, is addressed by its `#{session_id}` through `tgt()`, never by `=NAME`); a layout's own `name` goes through the same rules; an argument that ends in a semicolon is sent with a backslash in front of it (`targs()`: tmux would end the command there); a clash with a session of another path -> `parent-base`, then `parent-base-2..`; reuse = the session whose `@pj_path` (set on create) or `session_path` is the directory, never a `term-*`. **Layout** of a new session (two tmux calls, about 12 ms before the keys are typed: one chain with `new-session`/`new-window`/`split-window -P` printing the ids, one chain with `send-keys` + `select-window`; a chain that fails half way kills its half-built session, so the next Enter does not reuse a stump): repo = windows `code` (`nvim`, selected), `sh`, `ai`; plain directory = `sh`. Commands are typed into the interactive shell (`send-keys -l`, then Enter), so env, mise (DEV-b) and history apply and quitting nvim leaves a shell. **The `ai` window only TYPES `claude` without Enter** (`claude` on PATH; coordinator decision: it saves 300-500 MB per session; `ai_autostart = true` runs it, no `claude` on PATH = plain shell). Override: `<repo>/.tmux-session.toml` (`name`, `[[window]]` with `name` `[A-Za-z0-9_-]+` (no `.`: `-t =S:=a.1` is window `a`, pane 1) unique and never `wm-*`, `command`, `dir` relative and inside the repo (realpath), `focus`, `[[window.pane]]` with `command`, `split` right|below, `size` percent; each extra pane splits the window's first pane; unknown keys, bad names, an escaping `dir`, control characters in a command, a command over 200 characters or with a run of 10 spaces (the prompt must show all of it), more than one `focus` or more than 12 windows = error, nothing is created, "fix the file or open with the default layout: Alt+Enter"). **Trust**: the file is used only when its sha256 is in `~/.local/state/pj/trusted.tsv` (`path<TAB>sha256`, dir 0700, file 0600); a first use or a changed file shows a second fzf-menu (header = every command, wrapped to 100 columns, Unicode Cf/Zl/Zp characters such as a right-to-left override spelled `<U+202E>`; preview = the file, wrapped; rows `Use the default layout` first, `Trust this version and use it`); `t` / `pj trust [DIR]` do the same without opening (`--dry-run` only says what it would ask and writes nothing); the layout's own `name` only goes with its own windows. The file is read once (`read_small`: regular file, no symlink followed (`O_NOFOLLOW`), at most 64 KiB; a FIFO or a big file is `invalid`) and those same bytes are hashed and parsed. **`.workmux.yaml`** is behind the same trust (key `<repo>/.workmux.yaml` in `trusted.tsv`, `workmux_gate`): workmux reads the repo's own file (`post_create` hooks, pane commands), so `w` and Enter on a worktree row (which runs `workmux open`) ask first (header = the file's lines, preview = the file); no = workmux is not run (Enter on a worktree then opens a plain `wt-HANDLE` window), a changed file asks again; `t` and `pj trust` cover it and the preview line `workmux:` shows its state. Honest limit: it protects against a hostile cloned repo, not against a same-uid agent (same as mise/direnv trust), and it covers only the files themselves, not what they call: a trusted `command = "./dev.sh"` runs whatever `dev.sh` holds after the next `git pull`. **Enter** (decided once at start): inside tmux (prefix F, zsh widget, `--client`) `switch-client -c CLIENT`; plain terminal `tmux attach-session` as a child; Hyprland (`pj open`: float `fzf-menu --size large`, target = `HUB_TARGET` else `hyprctl -j activewindow`, recorded before the menu): (a) the target is a ghostty whose descendant (ppid walk of `list-clients` pids up to the window pid; several windows of one process: the title prefix `S:`) is a client of our server -> `switch-client` of that client, (b) else the session is shown in another window -> `hyprd focuswindow`, (c) else `ghostty -e tmux attach-session -t =S`. A td/yc window (their own server and uid) never matches, so SUPER+P over it opens a new window; Hyprland reachable = `HYPRLAND_INSTANCE_SIGNATURE` plus a writable socket (`PJ_HYPR=0|1` forces it). **term-\* rule**: `switch-client` of the last client away from a `term-*` session destroys it (`destroy-unattached`); pj checks the client's session first: idle shells only -> it goes (a throwaway terminal), something runs -> `destroy-unattached off` first and the message says it stays at the top of the picker and in "Clean up detached terminal sessions". "Runs" (`pane_busy`) is read from `/proc`: every non-idle process on the pane's terminal that descends from the pane's shell, so background jobs (`cmd &`) and stopped ones (Ctrl+Z) count, a process that forked away from the shell (wl-copy keeping the clipboard) does not, and **pj's own process group does not** (run from Ctrl+X p or typed in a `term-*` pane, pj is that pane's foreground job; before, every such switch leaked the idle terminal as a detached `term-*`). The picker rows use tmux's foreground command for sessions with a client (one tmux call) and the full scan for detached `term-*` leftovers; `term-procs.py` (SUPER+W, the cleanup row) counts background and stopped jobs the same way. **Keys in the list** (vimfzf NORMAL letters with ua/ru twins through `FZF_MENU_NORMAL_BINDS` = `become(printf query ACTION id)`, Alt keys through `--expect`, in `docs/keymap.md` as menu keys): `Enter` open, `o`/`Alt+O` a window of its own (Hyprland only, hidden otherwise), `d`/`Alt+D` kill (confirm when a pane runs a non-idle command (background and stopped jobs too), a client is attached or `wm-*` windows exist; attached clients move to the most recent other session first; the list reopens with the query kept), `w`/`Alt+W` workmux task, `c`/`Alt+C` clone (both hidden without workmux / without gh and glab), `t`/`Alt+T` trust, `Alt+Enter` default layout. Preview (`pj _preview ID`, each git call 1 s timeout and `--ignore-submodules=all`: `git status` takes 1.8 s in `tdesktop-unlocked`): session windows with busy marks, branch + ahead/behind + changed count, `git status --short` (15 lines), last commit, the layout state (`default` / `.tmux-session.toml trusted` / `NOT trusted: t to trust` / `invalid: ...`), README head (`bat`), `eza` for a plain directory. **workmux** (`w`): repo = repo row, a worktree row's repo or a session that sits in a repo; check the `.workmux.yaml` trust, branch picker first (`--print-query --expect=alt-enter`: Enter picks the highlighted free local branch or, when nothing matches, uses the typed name; **Alt+Enter uses the typed name as it is**, so `spa` is not turned into the fuzzy match `spare`; names starting with `-` or with odd characters are refused; a cancel leaves no session behind), then ensure the session and `workmux add BRANCH --parent-session S -b` in the repo with `TMUX=<socket_path>,<pid>,0` of pj's own server and no `TMUX_PANE` (so workmux talks to the same server, also in tests), the new `wm-*` window selected; output in `~/.local/state/pj/last.log` (0600), a failure shows its last line. pj itself never creates, renames or kills a `wm-*` window. Enter on a worktree row: a window whose pane path is inside the worktree (prefer `wm-*`) -> its session + window; else the parent repo's session and `workmux open HANDLE --parent-session S` (real workmux 0.1.276 checked: `add -b` and `open` both create `wm-<name>` in the parent session with no client attached); workmux missing or failing -> a plain `wt-HANDLE` window. **Clone** (`c`, `pj clone`, `pj open --clone`): `gh repo list --json nameWithOwner,description,isArchived,pushedAt` for the user and every `gh org list` org plus `glab repo list --mine -F json -P 100 -p N` (page after page until a short one) when glab is installed and logged in, cached in `~/.cache/pj/remote.json` (0600, 1 h; the picker opens with the cache at once and refreshes through `start:reload(pj _remote-rows --refresh)` when it is stale or missing, so no network on the main picker path); rows `gh  owner/name  description  [cloned]` (`origin` of every repo under the roots and `clone_dir` parsed from `.git/config` without git, compared by the whole path after the host so `grp/sub/repo` subgroups match; one walk per run; Enter on a cloned one opens it); destination prompt `--print-query --query=<clone_dir>/<name>`, an existing non-empty directory is refused; `gh repo clone` / `glab repo clone` run visibly in `--here` mode, silently with "Cloning" / "Cloned" notifications in float mode, log in `last.log`; the fresh clone is then opened like Enter (its `.tmux-session.toml` is untrusted by design); not logged in = one row `gh: not logged in, run gh auth login` (the owner step). `pj open --task` lists repo rows only and runs `w` on Enter. **td/yc**: `.local/bin/pj` is in the cli profile (with `fzf-menu`), their roots default to their own `~/job` + `~/dotfiles`, prefix F and Ctrl+X p work in their own tmux, no Hyprland paths and no notifications (messages go to `tmux display-message` or the terminal), `~/.config/pj/` and `~/.local/state/pj/` are their own. Test hooks (env): `PJ_CONFIG PJ_STATE_DIR PJ_CACHE_DIR PJ_TMUX PJ_HYPRCTL PJ_HYPRD PJ_TERMINAL PJ_ZOXIDE PJ_NOTIFY PJ_GH PJ_GLAB PJ_WORKMUX PJ_HYPR PJ_REPO PJ_WALK_ENTRIES PJ_WALK_MS PJ_TIMING=1` (prints the milliseconds until the fzf-menu request is sent; G2 <= 80 ms, measured 14 ms), `--dry-run` prints every tmux / hyprd / terminal / workmux / gh argv instead of running it. Tests: `infrastructure/tests/pj/run.sh [--quick] [--keep] [--only N]` (16 sections, one process each started in parallel with its own temp dir, fixture and private `tmux -L` server, output merged in section order: `--quick` takes about 2 s, the full run about 3 s; fakes in `bin/`, the real fzf-menu in a second private server for the modal test; clients attached through `script`, as in `tests/tmux-destroy`; the run has no `WAYLAND_DISPLAY` and the fake fzf-menu / ghostty come first on PATH, so no test can open a window on the desktop; sections 11-16: hostile names (`#` jobs, `$N` ids, `;`, dots), pj inside a `term-*` pane and background / stopped jobs, the `.workmux.yaml` trust and the branch picker, the layout-file limits and zsh as `default-shell`, the worktree cap and the walk budget, the zsh widget in a real interactive zsh). doctor: `pj` (`pj check`: config parses, roots exist or INFO, `hyprland.lua` SUPER+P calls `pj open`, `tmux.conf` prefix F calls pj, `sessionizer.sh` gone, cli profile lists pj), `pj-tests` (`--quick`), `pj-trust` (INFO count of trusted files (layouts and `.workmux.yaml`), FAIL when `~/.local/state/pj` is not 0700 or `trusted.tsv` not 0600).
